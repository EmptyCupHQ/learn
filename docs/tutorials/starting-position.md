# Starting position in 3D

Sometimes in a new project, if you go to 3D everything may appear black.

__This happens because you are standing outside the house.__

Press & hold the right or left arrow key on the keyboard to see in which direction you can find the house.

!!! warning Reset will not work

    In this case, even clicking on Reset does not work work because you are already at the startign position.


!!! tip Starting at the entrance

    To set the starting position at the entrace of the house:

    1. Go to 2D
    2. From the sidebar, select: Fittings > Hotspots > Entrance
    3. You will see a camera object appear on the floorplan.
    4. Place the camera object at the entrance of the house.
    5. Go to 3D.
    6. Select Walkin.
    7. Click Reset.
